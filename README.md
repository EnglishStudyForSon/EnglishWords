# 英语学习游戏中心

一个面向中小学生的英语单词学习游戏合集。目前包含两个游戏，由一个游戏中心页面统一入口。

## 游戏列表

| 游戏 | 目录 | 类型 | 玩法 |
|------|------|------|------|
| 🍄 超级玛丽学单词 | `mario/` | 2D HTML5 Canvas | 控制玛丽顶字母砖块，按顺序拼出单词 |
| ✈️ 3D 单词飞行 | `plane/` | 3D Three.js | 操控飞机按顺序穿过字母块拼词，飞过终点门过关 |

游戏中心 `index.html` 位于项目根目录，列出所有游戏，点击即全屏打开（在线加载，不解压不下载）。

## 游戏中心

- 根目录 `index.html` 是游戏列表页
- 点击卡片在应用内全屏打开游戏
- 每个游戏的 URL 在 `index.html` 顶部的 `GAMES` 数组配置

## 🍄 超级玛丽 · 顶字母学单词

一个超级玛丽风格的英语单词学习游戏。控制玛丽从下往上顶字母砖块，按正确顺序拼出单词；顶对会掉落蘑菇种子让蘑菇长高，顶错会被锤子砸矮蘑菇。纯 HTML5 Canvas 单文件实现，无任何依赖。

### 游戏规则

#### 目标

按正确顺序顶字母砖块，拼出屏幕顶部提示的中文所对应的英文单词。每完成一个单词蘑菇长高一截，一关的单词全部拼对后蘑菇正好长到云端，玛丽爬上云层过关。

#### 开局

点击「开始冒险」后浏览器进入全屏。单词按词库顺序选取，不随机：第 1 关取选中范围内的第 1–10 个词，第 2 关取第 11–20 个词，以此类推。默认全选 130 个词、每关 10 词，共 13 关。每关开始时会自动朗读一遍英文单词，HUD 顶部只显示中文释义。

单词范围、每关词数、容错次数、字母是否打乱都可以在**设置**里改，详见下方「设置」章节。

#### 字母砖块

单词的每个字母生成一块红砖，**顺序被打乱**，始终横向居中排成**一行**。字母多时砖块自动缩窄以容纳在同一行内（最窄 14px），不折行。空格与标点（`.` `!` 等）不生成砖块，会在底部槽位直接显示。

蘑菇绘制在砖块**下层**，且长高穿过字母行时会半透明化，因此不会挡住字母。

#### 拼词

跳跃从下往上顶砖（必须处于上升状态、头顶撞到砖块底部才算）：

- **顶对**（等于当前待拼位置的字母）→ 砖块变灰打勾、字母飞出、+10 分、朗读该字母、底部槽位填绿
- **顶错** → 错误音效、飞出 ✗、蘑菇处冒出锤击特效、扣 5 分、损失一颗 ❤、玛丽进入 200ms 闪烁冷却

顶砖不能跳步，必须严格按单词的字母顺序来。

#### 蘑菇成长

一个单词**完整拼对**后，会从砖块弹出一颗蘑菇种子；种子落地（或被玛丽在半空接住）触发浇水动画，蘑菇随之长高 1/10 云高。

顶错**不会**让蘑菇变矮，只消耗生命，所以一关的词拼完蘑菇必定刚好到达云端（长高量按本关实际词数均分）。

游戏过程中伞盖**不可站立**：字母占满整行宽度，站上伞盖会让玛丽的头高过砖块底部，那些字母就再也顶不到了。爬升由过场动画负责。

#### 完成一个单词

拼满所有字母后，全屏展示英文 + 中文、+50 分、金币与烟花庆祝、右侧词表记 ✅，2.4 秒后进入下一个单词。

#### 过关

本关最后一个单词的浇水完成、蘑菇触到云端时，播放**自动过场动画**：玛丽走到菇柄下 → 顺着菇柄向上攀爬 → 跃入云层淡出 → 显示「第 N 关 通过!」→ 进入下一关。玩家在过场中无需操作，右下角有「跳过 ▶▶」按钮可直接跳到结尾。

#### 错词补考

一关的主轮结束后，如果本关有拼错过的词（哪怕最终拼对了），会进入**补考轮**：这些词再考一遍，HUD 显示「补考 n/m」。补考轮照常计分，但不再影响蘑菇高度（主轮结束时蘑菇已到云端）。补考完成后才播过关动画。可在设置里关闭。

#### 失败

每关默认有 5 颗 ❤，顶错一次扣一颗；扣光即本局结束，当前词记 ❌。生命每关开始时重置，数量可在设置里改（3 / 5 / 10 / 无限）。

#### 暂停

点 HUD 的 ⏸ 或按 `Esc` / `P` 暂停。切换标签页或窗口失焦会自动暂停。暂停时游戏内的计时（过场、庆祝、进入下一词）一并冻结，语音立即停止，按住的方向键会被释放，恢复后不会突然窜出去。暂停面板可直接返回菜单，返回前会保存进度。

#### 听音拼写模式

设置里把「提示方式」改成**听发音**后，HUD 不显示中文释义，只提示「🔊 点击喇叭重听」。单词会以更慢的语速朗读两遍，🔊 按钮变成纯重听按钮（不再显示拼写、也不高亮正确砖块）。拼对整词后才揭示中文。

#### 连击

连续顶对字母累积连击，每 5 连提升 1 倍字母得分，最高 5 倍；顶错立即归零。连击达 5 以上时 HUD 左侧显示倍率与连击数（15 连变黄、25 连变紫），每跨过一档会弹出 `COMBO xN`。结算页显示本局最高连击。

#### 计分

- 每个正确字母：+10 分 × 连击倍率（1–5 倍）
- 每完成一个单词：+50 分
- 顶错一次：−5 分（不低于 0）

分数跨关卡累计，全部关卡通过后显示总成绩。通关时按错误数给 1–3 星（零失误 3 星），刷新最高分会标注「新纪录!」。

结算页列出本局所有单词：✅ 一次拼对 / ⚠️ 拼对但出过错 / ❌ 未完成，并显示该词的历史正确率，点任意一词可重听发音。

#### 学习记录

游戏会记住每个单词的对错次数（`localStorage`），据此提供：

- **继续冒险**：菜单上出现绿色「继续冒险」按钮，从第一个未通关的关卡接着打。中途从暂停面板退出也会保留已通关进度，不用从第 1 关重来。
- **最高分与进度**：菜单下方显示「已通关 N/M 关 · 最高分 X · 练过 Y 词」。进度按「单词总数 × 每关词数」分别记录，改了单词范围不会串到别的配置上。
- **只练错词**：设置里打开后，词池只保留错得多的词（错误数 ≥ 正确数）。没有错词记录时自动回退到完整选择，不会出现空词池。
- **熟练度显示**：设置的单词列表里，每个练过的词右侧显示 `3✓/1✗`，正确率 ≥80% 显示绿色、<50% 显示红色。
- **清除记录**：设置里可一键清空对错记录和通关进度。

### 设置

菜单页点 **⚙ 设置** 打开，菜单下方会实时显示当前配置摘要。所有设置存在 `localStorage`，下次打开自动恢复。

| 设置项 | 可选值 | 说明 |
|--------|--------|------|
| 提示方式 | 看中文 / 听发音 | 听发音模式隐藏中文释义，靠听力拼写 |
| 每关单词数 | 5 / 10 / 15 / 20 | 同时决定关卡总数和蘑菇每次长高的幅度 |
| 容错次数 | 3 / 5 / 10 / 无限 | 每关的 ❤ 数量，选「无限」时 HUD 显示 ∞ |
| 字母顺序打乱 | 打乱 / 按顺序 | 关掉则砖块按单词本身的字母顺序排列，适合入门 |
| 错词补考 | 开 / 关 | 本关结束后重考本关拼错过的词 |
| 只练错词 | 开 / 关 | 词池只保留错得多的词，标题旁显示待巩固数量 |
| 学习记录 | 清除记录 | 清空对错统计与通关进度 |
| 单词范围 | 9 个分类 · 130 个词 | 按分类整组勾选，或展开分类逐个勾选 |

**单词范围**分为水果、蔬菜、动物、地点与国家、职业、物主代词、家居与家务、形容词与描述、其他常用词共 9 类。分类标题的复选框有三种状态：全选（绿 ✓）、部分选中（黄 –）、未选。面板顶部有「全选 / 全不选」，标题右侧实时显示「已选 N 个 · M 关」。

选中的词按词库原顺序切分成关卡。若剩余尾数不足每关词数的 1/3，会并入最后一关；否则单独成为一个较短的末关，避免出现明显超长的关卡。选中数量不足一关时会红字提示，此时点「开始冒险」会直接打开设置面板。

## ✈️ 3D 单词飞行

一个 Three.js 3D 飞行游戏。操控飞机自动向前飞行，按正确顺序穿过字母方块拼出单词，最后飞过终点门过关。

### 游戏规则

- 飞机自动向前飞行，玩家控制上下左右移动
- 字母方块以弧线排列在航线上，按顺序穿过拼出单词
- **只认正确顺序**：碰对当前字母 → 收集加分；碰错 → 扣命 + 红屏闪烁
- 拼完单词后终点门出现在前方，飞过即过关进入下一词
- 漏掉字母会自动在前进方向重刷一组，不会卡关
- 生命 ❤ 扣光则游戏结束

### 操作方式

| 动作 | 键盘 | 触屏 |
|------|------|------|
| 上下左右 | `WASD` / 方向键 | 屏幕底部 ▲▼◀▶ 按钮 |
| 鼠标拖拽 | 拖动视角方向控制 | — |
| 发音提示 | — | 🔊 按钮（朗读单词） |

### 特性

- 屏幕中心**十字准星**辅助瞄准，对准字母（圆点变绿）直线飞行即可收集
- 当前待收集字母持续**脉动高亮**，一眼可辨
- 字母方块自适应间距，长单词整串保持在视野内不裁切
- 键盘 + 触屏按钮 + 鼠标拖拽三种控制方式
- Web Audio 音效（收集/错误/过关/失败）+ Web Speech 朗读

## 打包

### 网页版（Web 打包）

`build_web.bat` 将游戏打包为 zip 到 `dist/`：

```
dist/englishwords-hub.zip   — 游戏中心
dist/mario.zip              — 马里奥游戏
dist/plane.zip              — 3D 飞行游戏
```

### Android APK 打包

`build.bat` 将马里奥游戏打包为 Android APK（需 JDK 21 + Android SDK）：

```
android/app/build/outputs/apk/debug/app-debug.apk
android/app/build/outputs/apk/release/app-release.apk
```

- 依赖 Capacitor 8（`@capacitor/core` / `@capacitor/cli` / `@capacitor/android`）
- `capacitor.config.json` 配置 appId、应用名、`webDir: www`
- 密钥库 `mario-release.jks`（已被 `.gitignore` 排除）用于 release 签名
- APK 已锁定横屏（`AndroidManifest.xml` 的 `screenOrientation="landscape"`）
